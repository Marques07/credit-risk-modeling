# credit-risk-modeling

Projeto de análise e predição de inadimplência de crédito usando o dataset Home Credit Default Risk.

## Objetivo
Prever quais clientes têm maior probabilidade de dar default em um empréstimo, permitindo ações preventivas de contenção.

## Dataset
Home Credit Default Risk (Kaggle) - application_train.csv (307.511 linhas, 122 colunas)

## Stack
- Python 3
- pandas, numpy
- scikit-learn (KNN como baseline)
- VS Code + Kiro
